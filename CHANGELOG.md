# Changelog

All notable changes to Ratatata are documented in this file.

## [0.2.0] - 2026-09-13

### Added

- Enabled Ratatata's full bundled syntax set, adding automatic detection and
  highlighting for Ada, AWK, AsciiDoc, x86/x86_64 assembly, CFML, Cabal,
  CoffeeScript, Crystal, Dart, Elixir and EEx, Elm, F#, Fish, Fortran, GDScript,
  GLSL, GraphQL, Groff/troff, Idris, Jinja2, Jsonnet, Julia, Kotlin, Less, LLVM,
  Lean 4, LiveScript, MediaWiki, NSIS, Nim, Nix, Odin, Org mode, Protocol
  Buffers, Puppet, PureScript, QML, Racket, Rego, Robot Framework, Sass/SCSS,
  Slim, Solidity, Standard ML, Stylus, Svelte, Swift, SystemVerilog, Terraform
  and HCL, TypeScript and TSX, Twig, Typst, varlink, VHDL, Verilog, VimL, Vue,
  Vyper, WGSL, Zig, jq, and gnuplot.
- Added detection for Apache and nginx configuration, CMake, CSV and other
  separated-value files, cron tables, Dockerfiles, dotenv files, email,
  Git configuration and metadata, Go module files, INI files, Ninja files,
  package requirement files, SSH configuration and key files, system logs,
  TOML, Todo.txt, Unix system configuration files, man pages, and HTTP
  request/response files.
